# モンティ・ホール問題シミュレーター

3〜100枚のドアで「変える / 変えない」を体感し、戦略ごとの勝率を比較できる教材シミュレーター

🔗 **公開URL**: https://montyhall.meetupsensei.com/

## 概要

ドアの数を3〜100枚に変えて、「選択を変える」と「変えない」のそれぞれの戦略で何度も試行を行い、勝率の収束をリアルタイムで確認できるツールです。
